# danielherrmann.ca

Plain HTML, CSS and JavaScript. There is no build step on the server: the repository is the site.

## Pages

- `index.html`: home (hero, the simplex figure, the three research programs, talks, poem).
- `publications.html`: publications and talks; each entry has a `pub-*` id, and a link to `publications.html#pub-...` opens and highlights that entry.
- `about.html`: bio and photo.
- `contact.html`: email, profiles, working with students and collaborators.
- `404.html`: shown for any address that doesn't exist.

## Assets

- `assets/site.css`: layout, type, and the two palettes (Paper and Night).
- `assets/site.js`: palette toggle, figure captions, rolls strips, email link, publication anchors.
- `assets/prefs.js`: reads saved preferences before the page paints.
- `assets/background.js`: the simplex (home) and signaling-game figures, and the page-wide red pulse.
- `assets/definetti.js`, `assets/definetti-die.js`: the de Finetti figures (coin and die).
- `assets/delegate.js`: the delegation archery figure.
- `assets/xp-search.js`: the search tree that grows on hover over ∃xProof AI.
- `assets/Herrmann_CV.pdf`: the public CV (no references page).
- `assets/og-card.png`: the link-preview image (a 1200 × 630 layout rendered at 2x).
- `assets/fonts`: ET Book (MIT licence) and the ∃ glyph for the wordmark.

## Editing

You can edit the HTML directly. The pages were generated by `tools/build.py`; to use it instead, edit its sources and rebuild from the repository root:

```
python3 tools/pubs.py > tools/pubs.html   # after changing a publication in tools/pubs.py
python3 tools/build.py tools               # rebuilds the five pages
```

The About text is in `tools/home-main.html` and the Keats poem in `tools/keats.html`; everything else is in `tools/build.py`. `tools/og/gen.py` and `tools/og/render.js` regenerate the link-preview card (`python3 tools/og/gen.py && node tools/og/render.js F`, then copy `tools/og/og-F.png` to `assets/og-card.png`). `tools/verify-scenes.js` checks the figures' maths with Node.

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publishing on GitHub Pages

1. Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
2. Add a `CNAME` file containing `www.danielherrmann.ca`, and point the domain's DNS at GitHub Pages: a `CNAME` record for `www` to `<username>.github.io`, and `A` records for the bare domain to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153.
3. Once the certificate is issued, tick "Enforce HTTPS".
